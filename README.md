# Entrenadores PF

Prototipo web para profesores/entrenadores.

Incluye:
- Gestión de alumnos
- Biblioteca de ejercicios
- Creación de rutinas
- Selección de ejercicios por rutina
- Vista imprimible para guardar/enviar como PDF
- Guardado local en el navegador

Para GitHub Pages alcanza con subir `index.html`.
